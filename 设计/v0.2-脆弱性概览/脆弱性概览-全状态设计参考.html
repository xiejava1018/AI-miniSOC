正常态

有数据的标准展示

这是最常见的状态，页面有完整数据展示，所有组件正常渲染。

页面预览

关键特征：
  • 所有统计数据正常显示，数字清晰可读
  • 颜色编码：严重（红）、高危（橙）、中危（黄）、低危（绿）
  • 卡片可点击，悬停有视觉反馈（上移+发光）
  • Top 5列表完整渲染，资产信息完整
加载态

数据加载中

页面首次加载或刷新数据时，在数据返回前显示加载状态。

页面预览

正在加载脆弱性数据...

设计规范：
  • 显示居中的旋转Spinner
  • 下方显示"正在加载脆弱性数据..."文案
  • 所有交互元素禁用（点击无响应）
  • 超时时间：10秒，超时后显示错误态
空态

没有数据

系统中还没有任何脆弱性数据，用户首次使用或数据被清空时显示。

页面预览

暂无脆弱性数据

开始从Wazuh同步CVE漏洞和配置检查数据

立即同步数据
设计规范：
  • 显示友好的图标（盾牌+对勾）
  • 标题："暂无脆弱性数据"
  • 描述："开始从Wazuh同步CVE漏洞和配置检查数据"
  • CTA按钮："立即同步数据"，点击后跳转到同步页面
  • 不显示任何统计卡片或列表
错误态

数据加载失败

网络错误、服务器异常、API返回错误等情况时显示。

页面预览

加载失败

无法连接到服务器，请检查网络连接后重试

重新加载
错误场景细分：
  • 网络错误：显示"无法连接到服务器"
  • API错误：显示"服务器异常，请稍后重试"
  • 超时：显示"请求超时，请检查网络后重试"
  • 权限错误：显示"没有访问权限，请联系管理员"
设计规范：
  • 显示错误图标（圆圈+感叹号）
  • 标题根据错误类型动态变化
  • 描述文字简洁说明问题原因
  • CTA按钮："重新加载"，点击后重新请求数据

Toast汇总

操作反馈提示

所有用户操作和系统事件的反馈Toast汇总。

成功Toast

✓ 同步完成！新增23个CVE漏洞
✓ 配置检查同步完成！新增15个配置项
✓ 数据已更新

错误Toast

✕ 同步失败：网络连接超时
✕ 服务器错误，请稍后重试
✕ 没有权限访问该数据

警告Toast

⚠ Wazuh中暂无CVE漏洞数据
⚠ 部分数据加载失败
Toast规则：
  • 位置：页面顶部居中
  • 时长：成功2秒自动消失，错误5秒自动消失，警告3秒
  • 同时显示：最多同时显示3条，超过则排队等待
  • 可关闭：所有Toast可手动点击关闭
  • 动画：淡入淡出 + 从顶部下滑
交互规则

交互行为规则表

完整的用户操作与系统行为映射表，前端开发直接对照实现。

触发 用户操作 系统行为 反馈
用户 点击CVE漏洞卡片 跳转到 `/vulnerabilities/cve-list` 页面导航
用户 点击配置检查卡片 跳转到 `/vulnerabilities/sca-list` 页面导航
用户 点击"查看完整排行" 跳转到资产列表页面，按风险排序 页面导航
用户 点击单个资产行 跳转到 `/assets/{asset_id}` 页面导航
用户 点击最近发现CVE项 跳转到该CVE的详情页 页面导航
用户 点击配置检查项 跳转到该配置检查的详情页 页面导航
系统 页面加载 显示加载态 → 并发请求所有API → 渲染数据 Spinner → 页面内容
系统 数据加载成功 更新统计数据、排行列表、最近发现 无（静默更新）
系统 数据加载失败 显示错误态，隐藏所有数据卡片 错误提示 + 重试按钮
系统 数据为空 显示空态，引导用户同步数据 空态页面 + CTA
系统 部分数据失败 失败部分显示"加载失败"，其他正常显示 警告Toast
异常 网络超时（>10s） 取消请求，显示超时错误 错误Toast
异常 API返回500 显示服务器错误，提供重试选项 错误Toast
异常 API返回401 跳转到登录页 Toast: "请先登录"
边界情况处理：
  • 长文本截断：资产名称超过20字符显示省略号，悬停显示完整名称
  • 大量数据：排行列表固定Top 5，不展示分页或"查看更多"
  • 数值显示：统计数字超过999显示为"1.2K"，超过999999显示为"1.5M"
  • 时间显示：1小时内显示"X分钟前"，24小时内显示"X小时前"，超过显示"X天前"
  • 零值处理：统计为0时显示数字"0"，不显示横线或"无"
