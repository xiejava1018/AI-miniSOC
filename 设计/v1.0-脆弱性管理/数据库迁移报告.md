## 🔌 API端点验证

### 路由注册
- 基础路径: `/api/v1/vulnerabilities`
- 注册成功: ✅
- 路由数量: 13个端点

### 端点列表

#### 统计接口 (2个)
```
GET /api/v1/vulnerabilities/stats/overview
    - 功能: 获取漏洞统计概览
    - 返回: 各严重程度的漏洞数量

GET /api/v1/vulnerabilities/stats/ai-suggestions
    - 功能: 获取AI优先修复建议
    - 参数: limit (默认5)
    - 返回: Top N优先修复漏洞列表
```

#### 漏洞CRUD (2个)
```
GET /api/v1/vulnerabilities/vulnerabilities
    - 功能: 漏洞列表查询
    - 参数: skip, limit, severity, scanner, status, search
    - 返回: 分页漏洞列表

GET /api/v1/vulnerabilities/vulnerabilities/{id}
    - 功能: 漏洞详情查询
    - 返回: 单个漏洞完整信息
```

#### 资产-漏洞关联 (2个)
```
GET /api/v1/vulnerabilities/asset-vulnerabilities
    - 功能: 资产-漏洞关联列表
    - 参数: skip, limit, asset_id, severity, status, scanner
    - 返回: 分页关联列表

PATCH /api/v1/vulnerabilities/asset-vulnerabilities/{id}/status
    - 功能: 更新漏洞修复状态
    - 参数: status, notes
    - 返回: 更新成功消息
```

#### 扫描任务管理 (4个)
```
POST /api/v1/vulnerabilities/scan-tasks
    - 功能: 创建扫描任务
    - 返回: 任务信息

GET /api/v1/vulnerabilities/scan-tasks
    - 功能: 扫描任务列表
    - 参数: skip, limit, status, task_type
    - 返回: 分页任务列表

GET /api/v1/vulnerabilities/scan-tasks/{id}
    - 功能: 扫描任务详情
    - 返回: 任务完整信息

POST /api/v1/vulnerabilities/scan-tasks/{id}/cancel
    - 功能: 取消扫描任务
    - 返回: 取消成功消息
```
