## 任务清单

### T1 新增前端页面 `views/browsing/baseline/index.vue`
- **路径**：`src/frontend/src/views/browsing/baseline/index.vue`（目录若不存在则新建 `baseline/`）。
- **功能**：只读列表，展示 `soc_browsing_baseline`（IP×域名访问基线画像）。
- **筛选栏**（用 `ArtSearchBar`，仿 logs 页）：
  - `ip`：input，placeholder `如 192.168.0.8`，clearable；
  - `domain`：input，placeholder `域名关键字`，clearable。
  - 点击"查询"→ 以 `{ ip, domain }` 调 `getBrowsingBaseline`（空值传 `undefined` 以忽略该过滤，对齐后端"`ip` 精确 / `domain` ILIKE"语义）；"重置"→ 清空两项并刷新。
- **表格列**（用 `useTable` + `ArtTable`，仿 blacklist 页服务端分页范式）：
  | prop | label | 说明 |
  |---|---|---|
  | `ip` | 内网 IP | 居左，showOverflowTooltip |
  | `domain` | 域名 | 居左，showOverflowTooltip |
  | `total_count` | 累计访问次数 | 居中，width≈120 |
  | `first_seen` | 首次观测 | 居中，width≈170，格式化 `r.first_seen.replace('T',' ').slice(0,19)` |
  | `last_seen` | 末次观测 | 居中，width≈170，同上格式化 |
- **初始加载**：进入页面即带当前筛选条件调一次 `getBrowsingBaseline`（可先传空条件拉全量）。
- **文案/标题**：页内标题"行为基线"，可通过 `ArtTableHeader` 显示；不要新增/删除操作。
- **样式**：套用 `browsing-*-page art-full-height` + `art-table-card` 容器（同 blacklist/logs 页），保证全高与卡片风格一致。
