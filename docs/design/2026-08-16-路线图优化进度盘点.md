## 二、已落地能力的"价值"复述（不是清单，是为什么值）

- **P0 降噪**：把 Wazuh 海量原始告警按 `rule_id|agent_id` 聚成"告警簇"（实时 ~31 簇 / 快照累计 1775），解决了"告警噪声"这一 #1 痛点，让下游事件/报告不再是 GIGO。→ 这是整条链路的"入口闸"。
- **P1 脆弱性 + 事件**：脆弱性 2397 条落 PG 并可按 KEV 高亮；事件闭环打通"告警→事件→时间线→状态流转"，给了处置抓手。→ 这是"出口闸"。
- **P2 行为检测**：新增"内网主机行为画像 + 偏离检测"这一独立数据源，是"新数据源→检测→事件"闭环的样板。→ 扩展了检测面。
- **概览仪表板**：把上面三者收敛成一个作战视图，每个数字可下钻、带"今日需关注 N 项"和待办清单。→ 这是**激活"AI-SOC 实感"的关键收口**，中小企业兼职运营者 1 眼看清"今天有没有事、先动哪块"。

## 三、当前最该警惕的 3 个"已落地但未闭环"信号

> 这些不是 bug，是**产品健康度红灯**——功能有了，但没"转起来"。它们比 P3/P5 更该被优先看见。

1. **资产纳管率仅 30%（22/74）**——52 台资产处于监控盲区，没有 agent 就没有检测。这是比任何告警都更根本的风险敞口，应在仪表板/待办中顶到最前。
2. **事件闭环率 ~8%（仅 1 closed / 13）**——检测到了但处置不动，瓶颈在"人/流程"而非"系统"。漏斗图已暴露，但缺自动升级/提醒机制（指向 P5 SOAR）。
3. **AI 研判"群体强、个警弱" + 行为事件全 `new`**——群体 AI 研判 39 簇，但单告警自动研判仅 1 条；1040 条行为异常从未进入研判流转。说明 AI 能力偏"簇"级、单点覆盖几乎没用起来，且行为侧"检测→研判→事件"的链路断在最后一环。

## 四、剩余优化清单（按优先级）

### 🔴 P0 级阻断：P4 数据可靠性（现在最该做）
仪表板和所有 KPI 数字**可信的前提**就是 P4 修好。具体项：
- `ENCRYPTION_KEY` 非合法 Fernet 密钥 → 重启丢加密数据（生产前必修）；
- Loki 仅 7 天保留 + 单次 ≤10000 条分页 → 趋势/检索受限，需分页聚合；
- Alembic `alembic_version` 引用不存在修订 → 实际靠 `create_all` 启动，迁移链路断裂；
- `192.168.0.2` 日志凌晨 1:27 后中断（TL-R479GP-AC 路由器）→ 采集盲区；
- 测试 `tests/integration/test_user_workflow.py` envelope 断言需改 `body["code"]==201`；
- `soc_browsing_events.risk_score` 接口返回偶为 null → 评分回填链路待确认；
- **KEV∩漏洞=0**：PG 漏洞是真实 CVE 记录（非 mock），但 KEV 对齐未建立 → 仪表板"KEV 命中 0"应标"对齐待确认"而非"0 漏洞"。

### 🟡 P3：AI 资产增强（差异化卖点，路线图层）
风险评分 / 资产对账 / NL 查询（自然语言问资产）/ 自动报告。这是与通用 SOC 拉开差距的点，建议在 P4 之后启动。

### 🟢 P5：情报 / SOAR / 报告 / 知识库 / 多租户
威胁情报 feed 接入、SOAR 自动处置（直接缓解"事件闭环率 8%"）、报告生成、知识库、多租户规模化。

### 🔵 跨层：概览仪表板运行时验证
已提交但未在本会话跑真实环境 E2E。建议下一步拉起后端 + `curl /api/v1/dashboard/summary`，确认六数真实返回、RBAC 裁剪生效、KEV/Δ 口径与设计一致。

## 五、本迭代建议的下一步（Decision）

按"先治地基→再做差异化→最后规模化"的既有原则，**下一步应锁定 P4 数据可靠性**，理由：
1. 它是 P0–P2 已落地能力（尤其仪表板）**数字可信的前提**——不修，运营者不敢信仪表板；
2. 它是**生产可用的硬门槛**（Fernet 密钥非法 = 重启丢数据）；
3. 成本可控、范围清晰，不像 P3/P5 需要重新设计。

待 P4 收口，再依序推进 P3（差异化）→ P5（规模化 + SOAR 补事件闭环）。

---

## 六、非目标（Non-goals，防止范围蔓延）
- 本阶段**不**新增第 4 个检测数据源（P2 行为检测已够样板）；
- **不**在 P4 未修前做"报告生成"（垃圾进垃圾出）；
- **不**在 P3 之前做多租户（规模化是 P5 末段）；
- 仪表板**不**追求大屏炫技，坚持"可行动 + 显信任 + AI 差异化"三原则。
