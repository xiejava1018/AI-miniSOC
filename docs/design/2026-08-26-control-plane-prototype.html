新建扫描任务

按 v1.2 附录 C 字段契约 · 权限门 require_role("admin","operator")

基本

决定默认 nmap 参数与允许的目标类型。

校验 R1：每行须为合法 CIDR 或 IPv4。auto 路由时按 CIDR 匹配扫描器可达子网。

指派

auto：后端按 CIDR + 能力自动派发（如 192.168.0.0/24 → kali-45）；pinned：强制指定某台。

校验 R2：pinned 时必须选择。选项受 capabilities + reachable_subnets 过滤。

调度

校验 R4：由 central_scan_scheduler 解析，非法表达式阻断提交（原型不校验语法，仅演示）。
