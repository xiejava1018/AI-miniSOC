## 一、CMDB / 网络安全资产管理

### 1. 维易 CMDB (veops/cmdb) — 最推荐

| 属性 | 内容 |
|------|------|
| **GitHub** | [veops/cmdb](https://github.com/veops/cmdb) |
| **技术栈** | Flask + Vue.js + Ant Design Vue + MySQL + Redis |
| **License** | AGPL v3 |
| **特点** | 国产、中文、活跃维护、在线Demo |

**核心能力:**
- **自定义模型和模型关系**：支持模型属性的自定义，包括下拉列表、字体颜色、计算属性等高级功能，满足不同业务需求
- **自动发现资源**：支持计算机、网络设备、存储设备、数据库、中间件、公有云资源等自动发现
- **多维度视图展示**：包括资源视图、层级视图、关系视图等，帮助运维人员全面管理资源
- **细粒度权限控制**：通过精确的访问控制和完备的操作日志保障系统的安全性
- **全面的资源搜索功能**：支持灵活的资源和关系搜索，快速定位和操作资源
- **集成 IP 地址管理（IPAM）和数据中心基础设施管理（DCIM）**：简化网络资源和数据中心设备的管理
- **完善的REST API**：支持深度集成

**对AI-miniSOC的借鉴价值:**
- 模型自定义设计对AI-miniSOC的资产管理很有参考意义
- 自动发现机制可直接借鉴
- 关系视图设计对资产关联分析有帮助

## 二、攻击面管理 (ASM)

### 1. XingRin 星环 — 国产开源ASM

| 属性 | 内容 |
|------|------|
| **GitHub** | [yyhuni/xingrin](https://github.com/yyhuni/xingrin) |
| **技术栈** | 分布式架构 + Docker + Nuclei |
| **License** | GPL v3 |
| **特点** | 中文、现代化UI、分布式扫描 |

**核心能力:**
- **资产发现**：子域名枚举(subfinder/amass/puredns)、端口扫描(naabu)、站点识别(httpx)
- **漏洞扫描**：集成 Nuclei、Dalfox 等引擎，YAML 配置扫描流程
- **分布式架构**：多Worker节点、负载感知调度、SSH一键部署远程节点
- **资产快照**：扫描结果对比，追踪资产变化
- **定时扫描**：Cron表达式配置周期扫描
- **WebSocket实时通知**

**对AI-miniSOC的借鉴价值:**
- 资产发现流程设计（子域名→端口→站点→URL→目录→漏洞的完整链路）
- 分布式扫描架构（Master-Worker模式、负载感知调度）
- 与Nuclei集成的YAML编排方式

## 四、推荐方案

### 方案A: 借鉴维易CMDB增强现有资产模块 (推荐)

**策略:** 保持现有FastAPI + Vue3架构，借鉴维易CMDB的模型自定义和自动发现机制，升级AI-miniSOC资产管理模块。

**具体行动:**

1. **模型自定义**
   - 参考维易CMDB的模型属性配置（下拉、计算属性等）
   - 设计可扩展的资产模型定义接口
   - 支持自定义资产类型和属性

2. **自动发现增强**
   - 参考维易CMDB的自动发现机制
   - 扩展Wazuh现有资产发现能力
   - 增加网络设备、数据库、中间件等发现能力

3. **关系视图**
   - 借鉴维易CMDB的关系视图
   - 增加资产关联关系展示
   - 支持资产影响分析

---

### 方案B: 集成XingRin攻击面管理

**策略:** 将XingRin的资产发现和漏洞扫描能力集成到AI-miniSOC中，作为外部攻击面管理模块。

**具体行动:**

1. **资产发现流程**
   - 子域名枚举 → 端口扫描 → 站点识别 → URL收集 → 目录扫描 → 漏洞扫描
   - YAML配置扫描流程，灵活编排

2. **分布式扫描**
   - 参考XingRin的Master-Worker架构
   - 支持多节点部署和负载感知调度

3. **漏洞扫描集成**
   - 集成Nuclei扫描引擎
   - 与现有告警系统联动

---

### 方案C: 引入OWASP Amass作为资产发现引擎

**策略:** 将OWASP Amass作为外部资产发现引擎集成到AI-miniSOC中。

**优势:**
- 行业标准工具，社区活跃
- Go语言高性能
- OSINT信息收集能力强大
