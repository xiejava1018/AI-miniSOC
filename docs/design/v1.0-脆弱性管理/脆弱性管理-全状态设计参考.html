页面状态

加载态
触发条件：页面初次加载、刷新数据、扫描任务进行中
表现：显示加载动画 + 提示文字 + 可选的进度提示
正在加载漏洞数据...
这可能需要几秒钟
空态 - 无漏洞
触发条件：系统从未进行过扫描，或所有漏洞已修复
表现：友好的空状态插图 + 引导文案 + 操作按钮
太棒了！暂无漏洞
您的资产目前没有发现任何安全漏洞。建议定期运行扫描以保持系统安全。
空态 - 无资产
触发条件：系统中还没有添加任何资产
表现：提示用户先添加资产才能进行漏洞扫描
还没有资产
漏洞扫描需要先添加资产。请前往资产管理页面添加您的第一台服务器或设备。
搜索/筛选无结果
触发条件：用户搜索或筛选条件过于严格，没有匹配的结果
表现：提示无结果 + 清空筛选按钮
未找到匹配的漏洞
没有找到符合当前筛选条件的漏洞。尝试调整筛选条件或搜索关键词。
错误态 - 网络错误
触发条件：网络连接失败、API服务不可用
表现：错误图标 + 错误信息 + 重试按钮
连接失败
无法连接到服务器。请检查您的网络连接或稍后重试。
Error: Network request failed
Status: 503 Service Unavailable
错误态 - 扫描失败
触发条件：Wazuh/OpenVAS扫描任务执行失败
表现：具体的失败原因 + 建议操作
扫描任务失败
OpenVAS扫描任务执行失败，可能的原因：扫描器服务未启动、目标主机不可达、认证凭据无效。
Task ID: scan-20250325-001
Scanner: OpenVAS
Error: Connection timeout - target unreachable
部分可用状态
触发条件：部分数据源可用，部分失败（如Wazuh正常，OpenVAS不可用）
表现：同时展示成功和失败的状态，提供清晰的提示
Wazuh SCAP
扫描完成，发现23个漏洞
OpenVAS
连接失败，服务未启动

4. 扫描完成后刷新列表 		Toast: "扫描任务已创建" (成功)

用户 点击"查看详情" 1. 打开漏洞详情对话框
2. 加载该CVE的完整信息
3. 显示受影响资产列表 		对话框打开动画
加载中显示spinner
用户 使用搜索框 1. 实时过滤漏洞列表
2. 高亮匹配的文本
3. 显示匹配数量 		无结果时显示"未找到匹配的漏洞"
有结果时显示"找到X个匹配项"
用户 使用筛选器 1. 根据条件过滤列表
2. 更新URL参数
3. 更新统计数字 		筛选器高亮当前选中项
列表实时更新
用户 点击分页按钮 1. 计算分页范围
2. 加载对应页数据
3. 滚动到顶部 		按钮禁用状态更新
页码指示器更新

AI建议面板闪烁提示

红色闪烁动画
