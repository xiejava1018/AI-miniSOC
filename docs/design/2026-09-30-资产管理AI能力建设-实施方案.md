## 七、质量闸门（每任务必走）

| 维度 | 闸门 | 检查项 |
|---|---|---|
| 代码质量 | 风格 + 类型 | ruff + mypy + tsc |
| 测试 | ≥80% 覆盖 | pytest + vitest |
| 路由 | 端到端实测 | httpx/TestClient（CLAUDE.md 2026-08-22 教训） |
| 审计 | 全走 hash 链 | `audit_log_service` |
| 权限 | X1 矩阵 | `require_role` / `require_button_permission` |
| 降级 | 数据不全必声明 | `degraded=True` + 提示文案 |
| Envelope | body.code 而非 HTTP status | 前端 axios 拦截器 |
| CI/CD | 采集器走 `deploy_collectors.sh` | 健康门禁 + 死信记录 |
