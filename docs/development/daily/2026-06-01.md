### 1. 数据字典系统 (`soc_dicts`) — 完成

完成了数据字典从建模到前端 UI 的全链路实现，并将其应用到资产管理业务模块。

**后端**

- 新增 `soc_dicts` 表 SQLAlchemy 模型 + Pydantic schemas + Service + REST API

- 资产管理列表/详情页：删除所有硬编码 `assetTypeMap`/`criticalityMap`/
  `statusMap`，改从 `dictStore` 取值

**种子与数据迁移**

- `init_system_data.py` 写入 6 个字典分类共 19 条字典项
  (asset_type / asset_status / data_source / importance / network_zone / severity)
- 编写并执行 `migrate_assets_to_dict.py`，把 `soc_assets` 表中历史脏数据
  全部规范为字典 dict_code：
  - `asset_status`: 28 条 `在线`→`online`，8 条 `离线`→`offline`，
    1 条 `新发现`→`never_connected`
  - `criticality` / `asset_type` / `data_source` 23 条 NULL 全部补默认值
    (`medium` / `other` / `manual`)

### 3. 业务侧修复 — 完成

**`asset_sync.py`**

修复 Wazuh 同步写入中文标签的 bug：

```python
# 之前 (写入中文)
status_map = {"active": "在线", "disconnected": "离线"}

# 之后 (写入 dict_code)
status_map = {
    "active": "online",
    "disconnected": "offline",
    "never_connected": "never_connected",
}
asset_status = status_map.get(status, "unknown")
```

**后端驱动菜单**

- `menu_service.py`：原来只取 `is_visible=True` 的菜单，导致隐藏菜单
  （如资产详情）注册不到路由。改为取所有菜单，路由根据
  `is_visible` 标记 `isHide` / `isHideTab`。

**前端类型补全**

- `components.d.ts` 新增 `ElDescriptions` / `ElDescriptionsItem` /
  `ElTabs` / `ElTabPane` 全局组件类型
