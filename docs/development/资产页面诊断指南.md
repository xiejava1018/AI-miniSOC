# 资产页面数据不显示 - 诊断步骤

## 问题现象
资产管理页面无法显示数据，但数据库中有37条资产记录。

## 已确认信息
✅ 后端API正常：`curl http://localhost:8000/api/v1/assets/?limit=3` 返回正常
✅ 数据库有数据：返回 total=37
✅ 前端代理正常：`curl http://localhost:5173/api/v1/assets/?limit=3` 返回正常
✅ 后端服务运行中：http://localhost:8000

## 可能原因分析

### 1. 认证问题（最可能）
- **症状**：页面加载后立即跳转到登录页
- **原因**：Token过期或未登录
- **解决**：重新登录系统

### 2. API调用失败
- **症状**：控制台有红色错误信息
- **原因**：网络错误、权限问题、API返回错误
- **解决**：查看浏览器控制台错误信息

### 3. 数据处理错误
- **症状**：API返回正常，但前端未渲染
- **原因**：响应数据格式不符合预期
- **解决**：查看控制台日志中的数据结构

## 诊断步骤

### 步骤1：打开浏览器开发者工具
1. 按 F12 或右键 → 检查
2. 切换到 "Console" (控制台) 标签
3. 刷新资产页面 (Ctrl+R)

### 步骤2：检查认证状态
在控制台输入：
```javascript
localStorage.getItem('token')
```
- 如果返回 `null`：**需要重新登录**
- 如果返回token字符串：继续下一步

### 步骤3：检查Token是否过期
在控制台输入：
```javascript
const token = localStorage.getItem('token');
const payload = JSON.parse(atob(token.split('.')[1]));
console.log('过期时间:', new Date(payload.exp * 1000));
console.log('当前时间:', new Date());
console.log('是否过期:', payload.exp < Date.now() / 1000);
```

### 步骤4：查看详细日志
我已经添加了详细的日志输出，在控制台中查找：
- `[ApiClient]` 开头的日志 - API调用详情
- `[AssetStore]` 开头的日志 - 数据处理详情
- 任何红色的错误信息

### 步骤5：手动测试API
在控制台输入：
```javascript
fetch('/api/v1/assets/?limit=3', {
  headers: {
    'Authorization': 'Bearer ' + localStorage.getItem('token'),
    'Content-Type': 'application/json'
  }
})
.then(r => r.json())
.then(d => console.log('API返回:', d))
.catch(e => console.error('API错误:', e))
```
