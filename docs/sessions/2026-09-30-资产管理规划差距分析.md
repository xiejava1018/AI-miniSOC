## 一、执行摘要

规划核心主张：**2027 从"台账思维"跃迁到"本体治理"**——把资产从一行台账升级为可推理的本体图谱，AI 在图上完成融合、稽核、研判、优先级与整改闭环。

AI-miniSOC 当前定位：**资产图谱 + LLM 推理的"半成品本体"**（CLAUDE.md 已诚实标注 F3.1 降级版、Loki 不可达、SQL 图非 Neo4j）。

**契合度 ~45%**：13 个 AI 场景已落地 3 个（S8 影子 / S7 攻击路径 / S9 NLQ），部分 5 个，缺 5 个；本体层（§3）100% 缺失，是最关键缺口。

## 三、规划核心要求逐项对比

### 3.1 本体层（规划 §3）

| 规划要求 | AI-miniSOC 现状 | 评级 |
|---|---|---|
| Asset Ontology v1（YAML + OWL 双形态） | 无本体定义文件；schema 隐式散落在 SQLAlchemy 模型 | 🔴 |
| 顶层五分法（物理/数字/逻辑/人员/业务） | 仅 `Asset` 单类 + `BusinessSystem` 独立表 | 🔴 |
| 六类 AI 资产（模型/Agent/MCP/Key/Prompt/算力） | `ai_provider.py` 仅做配置层；Agent/Skills/MCP 未入图 | 🔴 |
| 约束公理（Web80/443 / 生产不允许高危漏洞 / Agent 白名单） | 无任何约束定义 | 🔴 |
| STIX 2.1 / ATT&CK / CVE-CWE-CAPEC 锚定 | 无 | 🔴 |

**唯一亮点**：`core/criticality.py` 三维度（业务影响 + 数据敏感度 + 等保）已落地，与规划"资产关键性系数"思路同构。

### 3.2 画像层（规划 §4 八维）

| 八维 | 现状覆盖 | 缺什么 | 评级 |
|---|---|---|---|
| ① 身份维 | `source_id` / `wazuh_agent_id` / `data_source` / `last_synced_at` | 无**多源 ID 映射表** / 无**身份置信度评分** | 🟡 |
| ② 归属维 | `business_unit`（72/73 NULL）+ 三维度重要性 + `BusinessSystem` 关联 | `owner_id` 大量空 / 无治理委员会 | 🟡 |
| ③ 技术维 | `os_name` / `os_version` / `hardware_info` JSONB / `asset_type` | 无 SBOM / 无组件级 | 🟡 |
| ④ 暴露维 | `public_ip` 单字段 / `exposure_level` | 无 NAT 推导 / 无内外网映射 / 无 7 天全端口探测 | 🔴 |
| ⑤ 脆弱维 | `risk_score` / `score_breakdown` JSONB | 漏洞→业务系统未走图谱重排 | 🟡 |
| ⑥ 威胁维 | `AssetIncident` / `risk_scored_at` | 无 ATT&CK 技战术映射 | 🟡 |
| ⑦ 合规维 | `compliance.py` 巡检 + `data_classification` | 无定级备案字段 / 无等保自动稽核 | 🔴 |
| ⑧ 行为维 | **无 UEBA**（仅有 IP 上网行为画像） | 缺账号行为基线 | 🔴 |

**画像卡 UI**：分散在 `list`/`detail`/`overview` 三页，**无统一"画像卡 + 八维 + AHS"视图**。

### 3.3 图谱层（规划 §5）

| 规划要求 | 现状 | 评级 |
|---|---|---|
| Neo4j（规划建议） | **SQL 图（PG）自研**：`GraphNode`+`GraphEdge`+`NetworkLink`+`AccountPerson` | 🟡（不同技术栈，但已落地） |
| 4 类 builder | ✅ AssetPortVuln / Identity / Topology / AlertGroup + ManualRelation | 🟢 |
| 4 类 query | ✅ get_neighbors / find_paths / impact_scope / vuln_chokepoints | 🟢 |
| 端点行为图 `(Host)-creates->(Process)` | 无 Sysmon / eBPF / EDR | 🔴 |
| 数据流转图 `(App)-calls->(Database)` | 无 APM / 数据库网关 | 🔴 |
| 身份共现图 `(Account)-uses->(Device)` | `IdentityEvent`/`IdentityBinding` 表已建，未串入图 | 🟡 |
| 融合准确率 ≥98% 量化 | `soc_asset_change_logs` 记录变更但无准确率指标 | 🟡 |
| 图谱扩容触发线 | 无 P95 看板 / 无扩容预案 | 🔴 |

### 3.4 推理层（规划 §2.1）
