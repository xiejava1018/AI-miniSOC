# 登录后跳回登录页问题分析与修复

> 现象：用户访问 `http://localhost:5173/#/auth/login?redirect=/`，输入账号密码点击登录后，URL 跳到 `/#/auth/login?redirect=/auth/login?redirect=/auth/login?redirect=/...`（不断累加），实际页面始终停在登录页。

> 修复日期：2026-08-16｜依据：puppeteer headless Chrome 复现 + axios 拦截器分析 + Pinia store 流分析

## 一、问题链路（根因）

整个链路有 **3 个串联的 bug**，任一被修复都能缓解，**全部修复** 才能彻底解决。

### Bug #1：`ArtNotification` 组件无条件在登录页拉未读数

**位置**：`src/components/core/layouts/art-notification/index.vue:174-178`

```ts
onMounted(() => {
  void notifStore.loadUnread()   // ← 无条件拉
  mittBus.on('openNotice', openFromBus)
})
```

`<ArtNotification>` 在 `App.vue` 无条件挂载（不依赖登录态），所以**未登录访问登录页时也会调 `/api/v1/notifications/unread-count`**。

### Bug #2：axios 响应拦截器对 401 无条件触发自动登出

**位置**：`src/utils/http/index.ts:101-114`

```ts
function handleUnauthorizedError(message?: string): never {
  const error = createHttpError(message || '登录状态已失效，请重新登录', ApiStatus.unauthorized)
  if (!isUnauthorizedErrorShown) {
    isUnauthorizedErrorShown = true
    logOut()  // ← 未登录时也调
    ...
  }
}
```

未登录时 unread-count 返回 `{code: 401, msg: "Not authenticated"}`（中间件把 HTTP 401 包装成 envelope）。axios 拦截器**无条件**调用 `logOut()`，把 `userStore.isLogin` 清为 `false`、清空 token、并 `router.push('/auth/login')`。

### Bug #3：`logOut()` 内部 redirect 路径误判导致 URL 累加

**位置**：`src/store/modules/user.ts:130`

```ts
// 原代码
const redirect = currentRoute.path !== '/login' ? currentRoute.fullPath : undefined
```

`RoutesAlias.Login = '/auth/login'`（不是 `/login`），所以判断失败，`redirect` 被设置为 `'auth/login?redirect=/'`（当前页路径），然后 `push` 时 query 携带这个 redirect。**第二次再触发 401**，URL 变成 `?redirect=/auth/login?redirect=/auth/login?redirect=/...`，**无限累加**。

## 二、用户看到的现象

1. **首次未登录访问** → unread-count 返回 401 → `logOut()` 把 userStore 清空、push `/auth/login` 带 redirect=`/auth/login?redirect=/`。
2. URL 累加，页面刷新重新跑守卫。
3. 守卫看到 `userStore.isLogin === false`，再次跳登录页，URL 继续累加。
4. 视觉上：用户**永远停在登录页**，URL 不断变长。

对用户报告的"登录成功后老是又回到登录页"：

- 如果用户**完全没登录**（localStorage 无 token）：每次刷新都触发 #1+#2+#3 → 立刻跳回登录页。
- 如果用户**已登录**：某个请求临时返回 401（token 过期、并发、或者后端 jwt 黑名单）→ 触发 #2+#3 → 跳回登录页。

## 三、修复

### 修复 1：axios 401 处理加"已登录守卫"（核心）

**文件**：`src/utils/http/index.ts`

```ts
function handleUnauthorizedError(message?: string): never {
  const error = createHttpError(...)
  const userStore = useUserStore()
  const wasLoggedIn = userStore.isLogin || !!userStore.accessToken

  if (wasLoggedIn && !isUnauthorizedErrorShown) {
    isUnauthorizedErrorShown = true
    logOut()
    ...
  }
  throw error
}
```

**关键**：未登录状态下的 401 是预期行为（登录页加载、captcha 校验、主动 logout 后等），不能误踢。

### 修复 2：`logOut()` redirect 路径判断修正

**文件**：`src/store/modules/user.ts`

```ts
const LOGIN_PATH = '/auth/login'
const isOnLoginPage = currentRoute.path === LOGIN_PATH || currentRoute.name === 'Login'
const redirect = !isOnLoginPage ? currentRoute.fullPath : undefined
```

不再因路径名错配（`'/login' vs '/auth/login'`）导致 redirect 累加。
