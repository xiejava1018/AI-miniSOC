## 📝 技术决策

| 决策 | 原因 | 影响 |
|------|------|------|
| 审计日志导出 CSV 绕过全局 http 工具，直接使用 axios + Blob | 全局 http 工具按 `Http.BaseResponse` 解析响应，无法处理 `text/csv` 二进制流 | 单点实现，但只在该页面使用，不影响其他模块 |
| 资产详情别名从 `/asset/detail` 改为 `/asset/detail/index` | vue-router 的 component 路径需要指向实际文件 `index.vue` 而非目录 | 修复资产详情 404 错误，与 dict/config 命名风格保持一致 |
| useTable 的 `paginationKey` 配置（dict/audit-log/config 三个列表页） | useTable 内部用 `current/size` 但后端 API 用 `page/page_size`，不配置会导致请求同时带两组参数，后端取 `page=1` 导致翻页失败 | 统一前后端分页键名约定，避免类似问题 |
| dev-daily-report skill 安装到 `C:\Users\xiejava\.claude\skills\`（用户级） | 全局可用，跨项目复用；同时本项目也受益 | 后续所有项目写日报更方便，触发词"写日报"自动启用 |
| 占位图片使用 Pillow 生成纯色 PNG 而非从原仓库复制 | 私有 GitLab 仓库可能无访问权限，本地生成最快 | 视觉效果一般，但功能上能跑通；后续如需美化可替换 |
