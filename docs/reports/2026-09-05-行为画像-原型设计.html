⚠️ 关于本原型：这是一个可交互的高保真原型，用于在设计评审阶段确认"画像详情页"的界面与交互， 不依赖后端。行为 Tab 的数据来自《AI-miniSOC · 上网行为画像报告》真实 POC 结果（Loki 原始日志逐条时间戳计数）； 风险 / 关系 / 异常判定三个 Tab 的数据来自本次 POC 的告警与认证抽取实查结果（如 .102：866 告警组 / 76,055 条 / 被登录 610 次）， 以 真实 标出；未装 agent 的设备（如 .8）相应分层显示"数据不足"空态——这正是产品上线后真实会遇到的两种状态。 点击左上角主体可切换查看不同设备的画像。

v2 更新（2026-09-06）：新增 L1 群体画像概览层 —— 解决"菜单叫行为画像（群体语义）、点进去却是某 IP 详情（个体语义）"的名实不符问题。
① L1 群体概览：回答"全网是什么样"——人设群体分布、全网活跃节律、兴趣构成、风险分层、数据可信度、画像主体列表。
② L2 单 IP 详情：回答"这个设备/人是什么样"——左栏身份档案卡（固定不随 Tab 切换）+ 右侧行为 / 风险 / 关系 / 异常 4 个 Tab。
③ 跳转交互：L1 主体列表点任意一行 → 进入 L2；L2 左上角「← 返回群体概览」面包屑 → 回 L1。也可用顶部层级切换器直接跳。

原型与《方案设计 v1.3》的对应关系

  • L1 群体画像概览（v2 新增）= 《两层结构改造方案》L1；回答"全网是什么样"——人设群体分布 / 全网节律 / 兴趣构成 / 风险分层 / 数据可信度 / 画像主体列表。主体列表点任意行 → 进入 L2。
  • 左栏身份档案卡 = 方案 §3 层1；固定不随 Tab 切换，含关联账号双向钻取。
  • 行为画像 Tab = 方案 §3 层2；严格沿用报告布局：画像标签置顶 → 24h 曲线 + 时段分布 → 星期×小时热力图 → 访问习惯构成 + 各时段在干什么 → 域名 TOP N。
  • 风险画像 Tab = 方案 §3 层3；指标卡 + 告警规则榜(risk_bars) + 漏洞严重度 + 暴露端口 + 趋势折线(数据足够时)。
  • 关系画像 Tab = 方案 §3 层4；rel_graph 关系网络(出边绿/入边蓝/外联红) + 同网段设备列表，点击节点钻取对方画像。⚠ 待补：真实平台当前只有三张表、无拓扑图（偏差 D2），需补 ECharts graph 力导向图。
  • 异常判定 Tab = 方案 §3 层5；异常信号清单(可审计证据) + 「生成安全事件/加白名单」处置按钮，并接回 §P1 事件闭环。
  • 标识条下方异常横幅 + 审计水印 = 方案 §3.0 / §6 合规要求。
